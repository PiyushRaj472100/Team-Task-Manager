# Team Task Manager

A comprehensive task management application designed to help teams collaborate, organize, and track their work efficiently.

## 🚀 Features

- **Task Management**: Create, edit, delete, and organize tasks
- **Team Collaboration**: Assign tasks to team members and track progress
- **Project Organization**: Group tasks into projects and categories
- **Priority Management**: Set task priorities and deadlines
- **Progress Tracking**: Monitor task completion and project status
- **User-friendly Interface**: Intuitive and responsive design

## 🚀 Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/PiyushRaj472100/Team-Task-Manager.git
```

2. Navigate to the project directory:
```bash
cd Team-Task-Manager
```

3. Install dependencies:
```bash
npm install
```

4. Start the development server:
```bash
npm start
```

5. Open your browser and navigate to `http://localhost:3000`

## 📖 Usage

### Basic Operations

1. **Create a Task**: Click the "Add Task" button and fill in the task details
2. **Assign Team Members**: Select team members from the dropdown when creating or editing tasks
3. **Set Priorities**: Choose priority levels (High, Medium, Low) for tasks
4. **Track Progress**: View task status and completion percentage on the dashboard

### Advanced Features

- **Project Management**: Create projects to organize related tasks
- **Team Analytics**: View team performance metrics and productivity reports
- **Notifications**: Receive updates on task assignments and deadline reminders
